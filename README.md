# Affine Mutations over a Finite Field (Cryptography)

> Computes the **lifetime of affine-mutation seeds** over the finite field 𝔽₈ = ℤ₂[x] / ⟨x³ + x + 1⟩, using symbolic polynomial arithmetic in Python.

## Problem

Start from a seed of polynomial vectors:

S₀ = ((1, x), (1 + x², 1 + x + x²))

New words are generated by repeatedly applying an affine transformation:

ω′ = ω₀ + T(ω(sₖ₋₁)),  where T(ω) = A·ω + v

Here **A** is a 2×2 matrix over 𝔽₈, **v** is a translation vector, and every result is reduced modulo the irreducible polynomial x³ + x + 1. The **lifetime** of a seed is the number of mutations before the sequence repeats. The program computes it for each translation vector **v** and prints every intermediate state in polynomial and binary form.

## Implementation

- `sympy.Poly` with `GF(2)` handles polynomial arithmetic mod 2, and `sympy.div` reduces by the field polynomial.
- `numpy` arrays hold the matrix–vector products.
- Helper functions:
  - `poly_a_binario` gives the 3-bit binary representation of a field element.
  - `T_w_sk_1` applies the affine map A·ω + v.
  - `omega_prime` combines the result with ω₀.
  - `residuo` performs the reduction modulo x³ + x + 1.

**Result:** for each of the translation vectors tested (v = [0,0], [0,1], [1,0], [1,1]), the seed reaches a lifetime of **63 mutations**. That is the maximum possible period, 2⁶ − 1, for a 6-bit state.
